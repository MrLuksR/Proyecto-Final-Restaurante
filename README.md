# NOMBRE DEL RESTAURANTE

# Descripción general

## Este proyecto es un sistema de gestión para un restaurante, desarrollado en Java utilizando el IDE IntelliJ IDEA.
## El objetivo es administrar los diferentes componentes del restaurante, como los productos, pedidos, clientes, mesas y personal, integrando una interfaz gráfica (UI) y una conexión a base de datos.
